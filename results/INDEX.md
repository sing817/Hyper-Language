# Test Results Index

## Structure

```
results/
├── test_results/
│   ├── test_results.json        # Machine-readable results
│   ├── test_report.md           # Markdown report
│   └── execution_log.txt        # Execution logs
├── test_outputs/
│   ├── translation_examples.txt
│   ├── mixed_language_tests.txt
│   └── edge_case_results.txt
├── archived_tests/              # Old test files (backup)
└── docs/                        # Documentation
    └── testing_methodology.md
```

## How to Generate Reports

1. Run main test harness:
   ```bash
   python3 test_harness.py
   ```

2. View results:
   ```bash
   cat results/test_results/test_report.md
   cat results/test_results/test_results.json
   ```

3. Compare benchmarks:
   ```bash
   python3 benchmark_compare.py
   ```

## Files Generated

- `test_results.json` - Complete test metrics (time, error rate, output samples)
- `test_report.md` - Human-readable report with tables and examples
- `execution_log.txt` - Timestamp logs of each test execution
- `benchmark_comparison.csv` - v5.3.1 vs baseline comparison
